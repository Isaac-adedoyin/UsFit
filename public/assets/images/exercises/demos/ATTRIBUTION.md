# Exercise demonstration photos

Photos in this directory are unmodified copies from [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), released under the [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md). Downloaded 2026-09-30. Filenames preserve the upstream exercise ID and photo number. The exact per-exercise sources are in `exercise-media.json` at the project root.

The machine lateral raise illustration lives in the sibling `library` directory. It is by roneydya, via [wger](https://wger.de/en/exercise/1654/view), licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), and is displayed unmodified. See that directory's attribution file.

Photos are position references, not an animation or a substitute for the accompanying technique instructions. Supported T-bar, V-bar pulldown and dumbbell split squat variations are identified in the interface.
